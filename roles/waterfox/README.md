# waterfox

Privacy-focused browser with extensive customization.

## Process

```mermaid
flowchart TD
    A[Start] --> B[Install waterfox]
    B --> C[Create profile directory]
    C --> D[Install ff-ultima theme]
    D --> E[Install extensions & Firefox Color]
    E --> F[Install userscripts]
    F --> G[Setup Stylus themes]
    G --> H[Manage bookmarks]
```

## Components

- **ff-ultima**: CSS theme for Firefox/Waterfox
- **addons**: Extensions, Firefox Color theme, userscripts, Stylus
- **bookmarks**: SQLite bookmark management
