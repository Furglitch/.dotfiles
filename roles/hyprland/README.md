# Hyprland Role

A role for Ansible to automate the install and management of the Hyprland desktop environment and related applications.

## What's Included

- `hyprland` - desktop environment
- `waypaper` - wallpaper manager for Wayland
- `hyprshot` - screenshot tool for Hyprland
- `hyprpolkitagent` - Polkit agent for Hyprland
- `uwsm` - Wayland session manager
- `xdg-desktop-portal-hyprland` - XDG desktop portal for Hyprland
- `wayle` - Top bar for Hyprland
- `catppuccin-cursors` - Catppuccin cursor theme
